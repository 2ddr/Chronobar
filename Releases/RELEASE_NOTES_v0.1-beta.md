# Chronobar v0.1 beta

First public beta of **Chronobar: Client Time Tracker**.

**Beta period:** all Pro gadgets are unlocked until **November 1, 2026, 00:00 UTC**. After that date the app switches to the Free edition automatically (3 clients, Default skin, 100% scale, no gadgets). Pro will return as a paid upgrade.

## What's inside

- Client time counter with a separate time for each client
- Countdown timer (Pro)
- RAM indicator, numbers or graph (Pro)
- Skins and scale 100% / 150% / 200% (Pro)
- Tray icon, snapping to screen edges, always on top
- Portable, offline, no telemetry

## Download

`Chronobar-Portable-v0.1-beta.zip`

Unzip anywhere you can write files and run the exe. Windows SmartScreen may warn about an unsigned app: click **More info**, then **Run anyway**.

## Known limitations

- The exe is not code-signed yet.
- No automatic reset of tracked time at midnight.
- Windows only.
